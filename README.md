# Best Cars Dealership Review Application

## Project Overview

This project is part of the IBM Full Stack Software Developer Capstone.

The Best Cars Dealership Review Application allows users to browse car dealerships, view dealer details, read customer reviews, and submit their own reviews.

## Technologies Used

- Django and Python — Backend development
- React and JavaScript — Frontend development
- Node.js and Express — Dealer review services
- MongoDB — Database
- Docker — Containerization
- IBM Cloud — Application deployment
- GitHub Actions — CI/CD

## Features

- User registration and login
- Browse dealerships by state
- View dealership details and reviews
- Submit customer reviews
- View car makes and models
- Sentiment analysis of reviews
